qrng-beacon-log

An hourly, commit-then-reveal, host-attested randomness log.

Each pulse fixes a 32-byte value before a given drand round exists, and publishes it after. The commitment is anchored to RFC 3161 timestamps, Rekor and OpenTimestamps, so a third party can check that a value was neither predicted in advance nor selected after the fact — not before, and not after.

Verify it yourself

pip install notbefore
notbefore verify

The verifier is pinned and vendored, runs offline against published keys, and emits a reproducible JSON transcript. It does not require trusting this site.

Published data

  • /chain/pulse-NNNN.json — every pulse record, signed. e.g. pulse-0001; full listing on GitHub. A signed, machine-readable index is published as the log checkpoint — see TLOG.md. An unsigned directory listing would carry no guarantee, so there isn't one.
  • PROTOCOL.md — pulse format and verification, normative
  • NOTBEFORE.md — what the guarantee is, and is not
  • CLAIMS.md · ERRATA.md — what is claimed, and every correction to it
  • HARDWARE.md — the attesting hosts and their clocks
