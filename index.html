NotBefore

An hourly, commit-then-reveal, host-attested randomness log.

Each pulse fixes a 32-byte value before a given drand round exists, and publishes it after — so a third party can check that a value was neither predicted in advance nor selected after the fact: not before, and not after.

Anchoring, precisely: two independent RFC 3161 timestamp tokens are published beside every pulse. Rekor entries with inclusion proofs, and OpenTimestamps submissions, live on the repository's anchors branch and are checked by the CLI from git — this site does not serve them. OpenTimestamps proofs complete once their calendar transaction has six Bitcoin confirmations (a few hours); at any moment the newest few are still pending. The live count is in every verify-chain run (ots_complete / ots_pending).

Log checkpoint

The log is an RFC 6962 Merkle tree over every pulse, published as a C2SP checkpoint in signed-note form:

/checkpoint            current signed head
/checkpoints/NNNNNN    per-size history

Origin notbefore.net/log. Anyone can recompute the root from the published pulses and check it against the head — the leaf is canonical(pulse record), the tree is RFC 6962 with no variations. See TLOG.md. Witness cosignatures are not yet collected, so a split view is presently detectable by a client comparing heads over time rather than by a third party.

Verify it yourself

pip install notbefore py_ecc
notbefore verify 49

Also needs git and openssl on PATH. Without py_ecc the drand BLS check cannot run and the CLI fails closed — it will not print a value it could not fully verify.

The verifier is pinned and vendored, reads the log from git as data, and emits a reproducible JSON transcript. It does not require trusting this site.

Use it

Pre-register the pulse and a purpose string before the hour exists, wait, then derive. A reviewer runs the same command and gets byte-identical output; the transcript JSON is the artifact to keep.

notbefore split  45 --purpose cohort-allocation-2026-09 --frac 0.8 cohort.txt   # cohort.txt.A / .B
notbefore sample 45 --purpose chart-audit-2026-09 --k 12 cohort.txt
notbefore assign 45 --purpose pilot-arms-2026-09 --arms 2 cohort.txt
notbefore id     45 --purpose blind-ids-2026-09 --from cohort.txt
notbefore explain 45          # a methods-section paragraph

Walkthrough, transcript schema and flags: USAGE.md. Contract: NOTBEFORE.md (draft 0.4). The hour has no value if its reveal failed — take the next eligible hour, never an earlier one.

Published data

  • /chain/pulse-NNNN.json — every pulse record, signed. e.g. pulse-0001; full listing on GitHub. A signed, machine-readable index is published as the log checkpoint — see TLOG.md. An unsigned directory listing would carry no guarantee, so there isn't one.
  • PROTOCOL.md — pulse format and verification, normative
  • NOTBEFORE.md — what the guarantee is, and is not
  • CLAIMS.md · ERRATA.md — what is claimed, and every correction to it
  • HARDWARE.md — the attesting hosts and their clocks
